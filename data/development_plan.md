## מצב נוכחי v1.0
פעולות CRUD עם localStorage
הצגת תאריכים בלוח העברי וסינון לפי חודש

אריזה ל-Electron עבור Windows ו-macOS

## בעיות ידועות

### 1. localStorage ב-Electron
הבעיה: localStorage עלול להימחק בהתקנה מחדש
הפתרון: מעבר לקובץ JSON ב-app.getPath userData דרך ipcRenderer ו-ipcMain
עדיפות: גבוהה

### 2. אבטחה
הבעיה: nodeIntegration true ו-contextIsolation false
הפתרון: הפעלת contextIsolation, כיבוי nodeIntegration, יצירת preload.js עם contextBridge
עדיפות: גבוהה לפני הפצה ציבורית

### 3. מיון תאריכים עבריים
הבעיה: מיון אלפביתי של חודשים עבריים לא נותן סדר כרונולוגי
הפתרון: שמירת תאריך גרגוריאני ISO לצד מחרוזת התצוגה
עדיפות: בינונית

### 4. כפילות מצב רוח בטופס עריכה
הבעיה: handleEdit מציג מצב רוח נוכחי פעמיים
התיקון: const moods = כללי שמח רגוע מרגש נוסטלגי עצוב
עדיפות: נמוכה
