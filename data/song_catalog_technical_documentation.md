# תיעוד טכני — קטלוג שירים אישי

## 1. סקירה כללית

פרויקט קטלוג שירים אישי הוא יישום Web קטן הפועל כולו בצד הלקוח.
מטרתו לאפשר למשתמש לנהל רשימת שירים אישית הכוללת הוספה, עריכה, מחיקה, חיפוש וסינון.

## 2. טכנולוגיות הפרויקט

HTML - מבנה ממשק המשתמש
JavaScript Vanilla JS - ניהול נתונים, LocalStorage, סינון, אירועים, DOM דינמי
LocalStorage - אחסון נתונים מקומי בדפדפן בפורמט JSON
Intl API לוח עברי - הצגת תאריכים לפי הלוח העברי עם he-IL-u-ca-hebrew

## 3. מבנה הפרויקט

index.html - ממשק המשתמש
script.js - כל הלוגיקה
style.css - עיצוב

## 4. מבנה הנתונים

כל שיר נשמר עם השדות: id, title, artist, isFavorite, dateAdded, url, mood

## 5. פונקציות מרכזיות

getSongs - שליפת שירים מ-LocalStorage
saveSongs - שמירת שירים ל-LocalStorage
getHebrewMonthAndYear - המרת תאריך ISO ללוח עברי
filterAndRenderSongs - סינון והצגת הרשימה
populateArtistFilter - בניית פילטר זמרים
populateMonthFilter - בניית פילטר חודשים עבריים
handleEdit - עריכת שיר קיים
renderSongsList - יצירת רשימת השירים

## 6. מנגנון הסינון

סדר הסינון: חיפוש חופשי, זמר, אהובים, חודש עברי, מצב רוח
מצבי רוח אפשריים: כללי, שמח, רגוע, מרגש, נוסטלגי, עצוב

## 7. יתרונות הארכיטקטורה

אין צורך בשרת, ביצועים מהירים, עבודה ללא אינטרנט

## 8. שיפורים אפשריים

מיון לפי תאריך, ייצוא JSON, תגיות, נגן מוזיקה, סנכרון עם שרת
